
For doing Realistic Concentration Jumps, use the script rcj.py

Install miniconda then issue:
```
conda create -n rcj
conda activate rcj
conda install numpy

python3 rcj.py
```

_rates.txt files are used for input and will be handled automatically.

Some examples are provided in the input_files directory

Alter values in rcj.py script to change parameters.
